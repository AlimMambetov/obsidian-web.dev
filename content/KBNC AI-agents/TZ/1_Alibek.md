## 👤 **АЛИБЕК — Backend-разработчик**

**Тема работы:** Разработка серверной части платформы «Лаборатория ИИ КБР»; проектирование базы данных и реализация API регистрации, аутентификации и подтверждения email.

**Тема НИР:** Разработка методов и алгоритмов создания интеллектуальных программных диалоговых агентов на основе мультиагентных нейрокогнитивных архитектур.

---

### Функциональные требования:

1) Спроектировать базу данных в MongoDB: создать схемы коллекций User, Agent, Task в соответствии с утверждённой архитектурой.
2) Настроить серверное окружение: установить Node.js, настроить подключение к MongoDB, подготовить структуру проекта (модели, контроллеры, роуты, миддлвары).
3) Реализовать API регистрации пользователя: создание записи в БД с хешированием пароля (bcrypt), валидация email на уникальность.
4) Реализовать API входа пользователя: проверка email и пароля, генерация и выдача JWT-токена (access + refresh).
5) Реализовать API подтверждения email: генерация verification-токена при регистрации, отправка письма со ссылкой подтверждения, обработка перехода по ссылке с активацией аккаунта.
6) Написать миграции и скрипты инициализации базы данных для создания коллекций и индексов.
7) Подготовить базовую структуру проекта с использованием Express/Fastify, организовать кодирование и документирование API.

---

### Количественные показатели эффективности:

| Показатель | План |
|------------|------|
| Количество моделей БД | 3 (User, Agent, Task) |
| Количество API-эндпоинтов | 4 (регистрация, вход, подтверждение email, повторная отправка) |
| Время отклика API | < 200 мс |
| Срок сдачи | 3 недели |

---

### Методика тестирования:

1) Проверить корректность работы API регистрации: создание пользователя, хеширование пароля, валидация email.
2) Проверить корректность работы API входа: генерация JWT, проверка пароля, обработка неверных данных.
3) Проверить корректность работы API подтверждения email: генерация токена, отправка письма, активация аккаунта, истечение срока токена.
4) Проверить обработку ошибок и краевых случаев (дублирование email, неверный пароль, просроченный токен).
5) Проверить производительность API под нагрузкой.
---

### Функциональная сборка:

1) Настроить окружение для разработки (development) и тестирования (test) с использованием environment variables.
2) Настроить логирование запросов и ошибок для отладки на ранних этапах.
3) Написать базовые скрипты для инициализации БД (создание индексов, тестовые данные).
4) Подготовить проект к деплою.
