# 📁 hooks/useScrollParallax.ts

```ts
import { useScroll, useTransform } from "framer-motion";

export const useScrollParallax = (start: number = 0, end: number = 1, outputStart = 0, outputEnd = 1) => {
  const { scrollYProgress } = useScroll();
  const value = useTransform(scrollYProgress, [start, end], [outputStart, outputEnd]);
  return value;
};
```

✅ Можно использовать для:

- движения блоков при скролле
    
- scale элементов
    
- opacity / fade

# 📌 2. Apple-style reveal секция с карточками

```tsx
import { motion } from "framer-motion";
import { fadeUp, listItem, staggerContainer, scaleIn } from "@/animations";
import { useScrollParallax } from "@/hooks/useScrollParallax";

const cards = ["Card 1", "Card 2", "Card 3", "Card 4"];

export const RevealSection = () => {
  // параллакс: карточки будут немного сдвигаться при скролле
  const parallaxY = useScrollParallax(0.2, 0.8, 50, 0);

  return (
    <motion.section
      initial="hidden"
      whileInView="visible"
      viewport={{ once: true }}
      style={{ perspective: 1000 }} // для 3D rotate эффекта
    >
      <motion.h2 variants={fadeUp}>Наши Продукты</motion.h2>

      <motion.div
        variants={staggerContainer}
        initial="hidden"
        whileInView="visible"
        viewport={{ once: true }}
        style={{ display: "flex", gap: 20 }}
      >
        {cards.map((card, i) => (
          <motion.div
            key={i}
            custom={i}
            variants={listItem({ direction: i % 2 === 0 ? "up" : "down", distance: 60 })}
            style={{ y: parallaxY }} // плавный сдвиг при скролле
          >
            <motion.div
              variants={scaleIn} // эффект появления с scale
              whileHover={{ scale: 1.05, rotateY: 10 }}
              style={{
                background: "#fff",
                padding: 20,
                borderRadius: 20,
                boxShadow: "0 10px 30px rgba(0,0,0,0.1)",
              }}
            >
              {card}
            </motion.div>
          </motion.div>
        ))}
      </motion.div>
    </motion.section>
  );
};
```

### 🔑 Что здесь происходит:

1. **Секция появляется при скролле** → `whileInView="visible"`.
    
2. **Список карточек** → `staggerContainer + listItem + index`.
    
3. **Параллакс по Y** → карточки слегка сдвигаются при скролле → эффект depth.
    
4. **Scale + RotateY при hover** → интерактивный Apple-style эффект.
    
5. **Perspective** на секции → для 3D rotate эффекта.

# 📌 3. Reveal с clip-path (mask) — эффект “появления снизу”

```tsx
<motion.div
  initial={{ clipPath: "inset(100% 0 0 0)" }}
  whileInView={{ clipPath: "inset(0% 0 0 0)" }}
  transition={{ duration: 0.8, ease: "easeOut" }}
  viewport={{ once: true }}
>
  <h3>Секция с mask/reveal эффектом</h3>
  <p>Контент появляется как будто выезжает снизу.</p>
</motion.div>
```

✅ Очень круто смотрится для заголовков и hero-блоков.

# 📌 5. Сочетание всех техник

1. Секция = `motion.section`
    
2. Заголовок = `fadeUp` + clip-path reveal
    
3. Список карточек = `staggerContainer` + `listItem` + index
    
4. Параллакс = `useScrollParallax`
    
5. Hover эффекты = scale + rotateY
    
6. FLIP layout = если меняется порядок карточек
    

---

# ⚡ Итоговый паттерн

- ✅ Scroll trigger: `whileInView` или `useInView`
    
- ✅ Staggered lists: `listItem` + `index`
    
- ✅ Параллакс: `useScrollParallax`
    
- ✅ Reveal: fade, scale, clip-path
    
- ✅ Hover/interactive: scale, rotateY
    
- ✅ Layout changes: `layoutTransition`
