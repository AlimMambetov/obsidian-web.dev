# 📋 Анимации списков с index и кастомными параметрами

## 1️⃣ Универсальная функция variants с direction

```ts
import { Variants } from "framer-motion";

type Direction = "up" | "down" | "left" | "right";

interface ListItemOptions {
  direction?: Direction;
  distance?: number;
}

export const listItem = ({ direction = "up", distance = 50 }: ListItemOptions): Variants => {
  const offsets = {
    up: { y: distance },
    down: { y: -distance },
    left: { x: distance },
    right: { x: -distance },
  };

  return {
    hidden: {
      opacity: 0,
      ...offsets[direction],
    },
    visible: (i: number) => ({
      opacity: 1,
      x: 0,
      y: 0,
      transition: {
        delay: i * 0.1, // stagger через index
        duration: 0.5,
        ease: "easeOut",
      },
    }),
  };
};
```

💡 Обратите внимание: функция возвращает **Variants**, а в `visible` мы используем `(i: number) => {...}` для stagger через **index**.

---

## 2️⃣ Пример использования в компоненте

```tsx
import { motion } from "framer-motion";
import { listItem } from "@/animations/list-slide-variants";

const items = ["Первый", "Второй", "Третий"];

export const List = () => {
  return (
    <motion.ul initial="hidden" animate="visible">
      {items.map((text, i) => (
        <motion.li
          key={i}
          custom={i} // передаем index в variants
          variants={listItem({ direction: "up", distance: 40 })}
        >
          {text}
        </motion.li>
      ))}
    </motion.ul>
  );
};
```

✅ `custom={i}` позволяет `Variants` знать порядковый номер элемента и делать stagger.

---

## 3️⃣ Можно передавать любые данные

Например, direction, distance, скорость анимации и т.д.:

```tsx
{items.map((text, i) => (
  <motion.li
    key={i}
    custom={i}
    variants={listItem({ direction: i % 2 === 0 ? "left" : "right", distance: 30 + i * 10 })}
  >
    {text}
  </motion.li>
))}
```

👉 Тут:

- четные элементы будут сдвигаться **влево**
    
- нечетные — **вправо**
    
- расстояние увеличивается по index

## 4️⃣ Stagger контейнер

Чтобы все выглядело красиво, обычно комбинируют с контейнером:

```ts
import { Variants } from "framer-motion";

export const staggerContainer: Variants = {
  hidden: {},
  visible: {
    transition: {
      staggerChildren: 0.15, // общий stagger между элементами
    },
  },
};
```

Использование:

```tsx
<motion.ul
  variants={staggerContainer}
  initial="hidden"
  whileInView="visible"
  viewport={{ once: true }}
>
  {items.map((text, i) => (
    <motion.li key={i} custom={i} variants={listItem({ direction: "up" })}>
      {text}
    </motion.li>
  ))}
</motion.ul>
```

# ⚡ Полезные паттерны

1. **Разные анимации по index**  
    → Можно менять direction, delay, scale, color и т.д. через `custom` и `index`.
    
2. **Комбинируем с scroll**  
    → Каждый элемент анимируется при появлении на экране (`whileInView`).
    
3. **Reusable animation system**  
    → Все варианты (`listItem`, `fadeIn`, `scaleIn`) выносим в отдельный `/animations` файл и импортируем.

# 📁 animations.ts

```ts
// animations.ts
import { Variants } from "framer-motion";

/** -----------------------------
 * Общие анимации элементов
 * ----------------------------- */

// Fade In
export const fadeIn: Variants = {
  hidden: { opacity: 0 },
  visible: { opacity: 1, transition: { duration: 0.4, ease: "easeOut" } },
};

// Scale In (pop эффект)
export const scaleIn: Variants = {
  hidden: { opacity: 0, scale: 0.8 },
  visible: {
    opacity: 1,
    scale: 1,
    transition: { type: "spring", stiffness: 200, damping: 20 },
  },
};

/** -----------------------------
 * Анимации для списков с index и кастомными параметрами
 * ----------------------------- */

type Direction = "up" | "down" | "left" | "right";

interface ListItemOptions {
  direction?: Direction;
  distance?: number;
  duration?: number;
}

export const listItem = ({
  direction = "up",
  distance = 50,
  duration = 0.5,
}: ListItemOptions = {}): Variants => {
  const offsets = {
    up: { y: distance },
    down: { y: -distance },
    left: { x: distance },
    right: { x: -distance },
  };

  return {
    hidden: { opacity: 0, ...offsets[direction] },
    visible: (i: number) => ({
      opacity: 1,
      x: 0,
      y: 0,
      transition: {
        delay: i * 0.1,
        duration,
        ease: "easeOut",
      },
    }),
  };
};

// Контейнер с глобальным stagger
export const staggerContainer: Variants = {
  hidden: {},
  visible: {
    transition: {
      staggerChildren: 0.15,
    },
  },
};

/** -----------------------------
 * Scroll-ready анимации
 * ----------------------------- */

// Fade Up при скролле
export const fadeUp: Variants = {
  hidden: { opacity: 0, y: 40 },
  visible: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.6, ease: "easeOut" },
  },
};

// Slide Up при скролле
export const slideUp: Variants = {
  hidden: { opacity: 0, y: 50 },
  visible: { opacity: 1, y: 0, transition: { duration: 0.5, ease: "easeOut" } },
};

// Hover preset (scale)
export const hoverScale = {
  whileHover: { scale: 1.05 },
  whileTap: { scale: 0.95 },
};

// Layout / FLIP transition
export const layoutTransition = {
  type: "spring",
  stiffness: 300,
  damping: 30,
};
```

# 📌 Использование в компоненте

```tsx
import { motion } from "framer-motion";
import { listItem, staggerContainer, fadeUp, hoverScale } from "@/animations";

const items = ["Первый", "Второй", "Третий", "Четвертый"];

export const AnimatedList = () => (
  <motion.ul
    variants={staggerContainer}
    initial="hidden"
    whileInView="visible"
    viewport={{ once: true }}
  >
    {items.map((item, i) => (
      <motion.li
        key={i}
        custom={i} // index для stagger
        variants={listItem({ direction: i % 2 === 0 ? "left" : "right", distance: 30 + i * 10 })}
        {...hoverScale} // hover эффект
      >
        {item}
      </motion.li>
    ))}
  </motion.ul>
);
```

✅ Что получаем:

1. **Список с stagger** — элементы появляются с небольшой задержкой.
    
2. **Кастомная анимация через index** — можно менять direction, distance и delay.
    
3. **Hover эффекты на каждом элементе**.
    
4. **Scroll trigger** — анимация срабатывает только при появлении на экране (`whileInView`).
