## 🎬 Шпаргалка по Framer Motion (TypeScript): анимации, скролл, триггеры и продвинутые фишки

Эта шпаргалка — концентрат практики по **Framer Motion + TypeScript**: от базовых `variants` до анимаций при скролле, триггеров секций и эффектов вроде `flip`, `scale`, layout-анимаций и т.д.

---

# 🚀 Быстрый старт (TS)

```tsx
import { motion } from "framer-motion";

export const MyComponent = () => {
  return (
    <motion.div
      initial={{ opacity: 0 }}
      animate={{ opacity: 1 }}
      transition={{ duration: 0.5 }}
    >
      Hello Motion
    </motion.div>
  );
};
```

---

# 📦 Variants — основа архитектуры анимаций

👉 **Variants** — это декларативный способ управлять состояниями анимации.

```tsx
import { Variants, motion } from "framer-motion";

const boxVariants: Variants = {
  hidden: { opacity: 0, y: 50 },
  visible: { opacity: 1, y: 0 },
};

export const Box = () => (
  <motion.div
    variants={boxVariants}
    initial="hidden"
    animate="visible"
  />
);
```

### 💡 Почему это важно:

- масштабируемость
    
- переиспользование
    
- централизованная логика

# 🧠 Продвинутая работа с variants

## 1. Динамические variants

```tsx
const itemVariants: Variants = {
  visible: (i: number) => ({
    opacity: 1,
    transition: {
      delay: i * 0.2,
    },
  }),
  hidden: { opacity: 0 },
};

<motion.div custom={2} variants={itemVariants} />
```

👉 Используй `custom`, чтобы передавать параметры

---

## 2. Stagger-анимации (цепочки)

```tsx
const container: Variants = {
  visible: {
    transition: {
      staggerChildren: 0.2,
    },
  },
};

const item: Variants = {
  hidden: { opacity: 0 },
  visible: { opacity: 1 },
};
```

# 📜 Анимации при скролле (Scroll Animations)

## 🔥 Способ 1: whileInView (самый простой)

```tsx
<motion.div
  initial={{ opacity: 0, y: 50 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true, margin: "-100px" }}
>
  Контент
</motion.div>
```

### ⚙️ Важные параметры:

- `once: true` — анимация только один раз
    
- `margin` — заранее триггерит (как rootMargin)
    

---

## 🔥 Способ 2: useInView (контроль вручную)

```tsx
import { useInView } from "framer-motion";
import { useRef } from "react";

const ref = useRef(null);
const isInView = useInView(ref, { once: true });

<motion.div
  ref={ref}
  animate={isInView ? "visible" : "hidden"}
  variants={boxVariants}
/>
```

👉 Используй, если:

- нужна логика (API, state)
    
- сложные сценарии

# 🎯 Анимация при достижении секции

Типичный кейс: "доскроллил до блока — запускаем анимацию"

```tsx
const Section = () => {
  const ref = useRef(null);
  const isInView = useInView(ref);

  return (
    <section ref={ref}>
      <motion.div
        animate={isInView ? "visible" : "hidden"}
        variants={boxVariants}
      />
    </section>
  );
};
```

# 🧩 Scroll-linked анимации (привязка к скроллу)

```tsx
import { useScroll, useTransform, motion } from "framer-motion";

const { scrollYProgress } = useScroll();

const scale = useTransform(scrollYProgress, [0, 1], [0.5, 1]);

<motion.div style={{ scale }} />
```

👉 Можно делать:

- параллакс
    
- прогресс-бары
    
- reveal эффекты

# 🔄 FLIP-анимации (layout)

Framer Motion автоматически реализует FLIP 🔥

```tsx
<motion.div layout />
```

### 📌 Когда использовать:

- изменение размеров
    
- reorder списков
    
- grid → list
    

---

## ✨ Layout + shared layout (магия)

```tsx
<motion.div layoutId="card" />
```

👉 Один `layoutId` = плавный переход между компонентами

# 🔍 Scale / Flip / Transform фишки

## Scale

```tsx
<motion.div whileHover={{ scale: 1.1 }} />
```

## Flip (через rotate)

```tsx
<motion.div animate={{ rotateY: 180 }} />
```

⚠️ Не забудь:

```css
transform-style: preserve-3d;
```

---

## Комбинированные трансформации

```tsx
<motion.div
  animate={{
    scale: 1.2,
    rotate: 10,
    x: 100,
  }}
/>
```

# 🧪 Transition — тонкая настройка

```tsx
transition={{
  type: "spring",
  stiffness: 200,
  damping: 20,
}}
```

### Основные типы:

- `spring` (натурально)
    
- `tween` (линейно)
    
- `inertia`

# 🧠 Полезные паттерны

## 1. Reveal список при скролле

```tsx
<motion.ul
  variants={container}
  initial="hidden"
  whileInView="visible"
>
  {items.map((_, i) => (
    <motion.li key={i} variants={item} />
  ))}
</motion.ul>
```

---

## 2. Lazy анимации секций

👉 Разбивай страницу на секции и каждая сама управляет своей анимацией через `whileInView`

---

## 3. Избегай частых ошибок

❌ Анимация дергается  
→ проверь `key`

❌ Не работает layout  
→ нужен `layout` или `layoutId`

❌ Скролл не триггерится  
→ настрой `viewport.margin`

# ⚡ Итог
