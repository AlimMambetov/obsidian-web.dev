# 🧩 Зачем выносить анимации в отдельный файл

✅ Плюсы:

- переиспользование
- единый стиль анимаций
- проще поддержка
- чище компоненты

---

# 📁 Структура проекта

```bash
animations/
  fade.ts
  slide.ts
  scale.ts
  layout.ts
  index.ts
```

# 🧠 1. Базовый пример (fade.ts)

```ts
import { Variants } from "framer-motion";

  hidden: {
    opacity: 0,
  },
  visible: {
    opacity: 1,
    transition: {
      duration: 0.4,
    },
  },
};
```

---

# 🧠 2. Slide + direction (универсальная анимация)

```ts
import { Variants } from "framer-motion";

type Direction = "up" | "down" | "left" | "right";

export const slideIn = (direction: Direction, distance = 50): Variants => {
  const map = {
    up: { y: distance },
    down: { y: -distance },
    left: { x: distance },
    right: { x: -distance },
  };

  return {
    hidden: {
      opacity: 0,
      ...map[direction],
    },
    visible: {
      opacity: 1,
      x: 0,
      y: 0,
      transition: {
        duration: 0.5,
      },
    },
  };
};
```

# 🚀 Использование в компонентах

## 🔥 Самый быстрый способ (scroll)

```tsx
import { motion } from "framer-motion";
import { fadeUp } from "@/animations";

<motion.div
  variants={fadeUp}
  initial="hidden"
  whileInView="visible"
  viewport={{ once: true }}
>
  Контент
</motion.div>
```

---

## 🎯 С направлением

```tsx
import { slideIn } from "@/animations";

<motion.div
  variants={slideIn("left")}
  initial="hidden"
  whileInView="visible"
/>
```

# 🎯 Анимации при достижении секции (правильный подход)

👉 Делай универсальный хук

```ts
import { useInView } from "framer-motion";
import { useRef } from "react";

export const useScrollAnimation = () => {
  const ref = useRef(null);
  const isInView = useInView(ref, { once: true });

  return { ref, isInView };
};
```

Использование:

```tsx
const { ref, isInView } = useScrollAnimation();

<motion.div
  ref={ref}
  variants={fadeUp}
  initial="hidden"
  animate={isInView ? "visible" : "hidden"}
/>
```

# ⚠️ Частые ошибки

❌ Дублируешь анимации в компонентах  
→ выноси в `/animations`

❌ Нет типизации  
→ всегда `Variants`

❌ Смешиваешь inline + variants  
→ выбирай один подход

---

# 🧠 Итоговая стратегия

👉 Делай так:

- **variants → в TS файлы**
    
- **компоненты → только используют**
    
- **scroll → через whileInView**
    
- **сложные кейсы → useInView**
    
- **повторяемые эффекты → presets (hover, cards, sections)**

# 💡 Pro-уровень совет

Сделай себе “дизайн-систему анимаций”:

```ts
export const animations = {
  fade: fadeIn,
  fadeUp,
  slideIn,
  scaleIn,
  staggerContainer,
};
```

И потом:

```tsx
<motion.div variants={animations.fadeUp} />
```
