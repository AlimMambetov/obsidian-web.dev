## **Теория:**
---

- `let` — изменяемая переменная
- `const` — константа (нельзя менять)
- `querySelector()` — поиск элементов
- `addEventListener()` — обработка кликов
- Data-атрибуты — хранение состояния в HTML
- Условия `if/else if` — логика программы

#### **Типы данных:**
- `string` — текст (например: `"Привет"`)
- `number` — числа (например: `5`, `3.14`)
- `boolean` — логический тип (`true`/`false`)
- `null` — специальное значение "ничего"
- `undefined` — значение не определено
- `object` — коллекция данных (будет в след. уроках)
- `array` — список значений (будет в след. уроках)

#### **Основные операторы:**
- `=` — присвоить значение
- `+` — сложить числа или соединить строки
- `++` — увеличить на 1
- `--` — уменьшить на 1
- `>` — больше
- `<` — меньше
- `>=` — больше или равно
- `<=` — меньше или равно
- `===` — строгое равно (проверяет и значение, и тип)
- `!==` — не равно
####  **Условные операторы:**
- `if` — если условие истинно
- `else if` — иначе если (дополнительное условие)
- `else` — иначе (когда все условия ложны)

### **Логические операторы:**
- `&&` — И (оба условия должны быть true)
- `||` — ИЛИ (хотя бы одно условие должно быть true)
- `!` — НЕ (инвертирует значение)

### JS
```javascript
// Объявляем переменную счётчика
let clickCount = 0;

// Находим элементы на странице
const counterElement = document.querySelector('#counter-display'); // Дисплей счётчика
const btnClick = document.querySelector('[data-btn="click"]'); // Кнопка клика
const btnClear = document.querySelector('[data-btn="clear"]'); // Кнопка сброса

// Устанавливаем начальное значение
counterElement.textContent = `Кликов: ${clickCount}`;

// Вешаем обработчики событий на кнопки
btnClick.addEventListener('click', clickAction); // При клике увеличиваем
btnClear.addEventListener('click', resetAction); // При клике сбрасываем

// Функция для увеличения счётчика
function clickAction() {
  clickCount++; // Увеличиваем на 1
  checkState(); // Проверяем состояние
}

// Функция для сброса счётчика
function resetAction() {
  clickCount = 0; // Обнуляем
  checkState(); // Проверяем состояние
}

// Функция проверки состояния и обновления интерфейса
function checkState() {
  // Обновляем текст счётчика
  counterElement.textContent = `Кликов: ${clickCount}`;
  // Начальное состояние
  let state = 'default';  

  // Если >=50 - сбрасываем счётчик
  if (clickCount >= 50) clickCount = 0;
  else if (clickCount >= 20) state = 'max';
  else if (clickCount >= 10) state = 'center';
  else if (clickCount > 0) state = 'start';

  // Устанавливаем data-атрибут состояния
  // Это автоматически применит CSS-стили (меняется цвет)
  counterElement.dataset.state = state;
}
```

**Мини-проект:** Создать интерактивный счетчик с визуальной обратной связью.
